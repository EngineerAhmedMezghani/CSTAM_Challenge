# `architecture.excalidraw` — Notes

## Purpose

The file `architecture.excalidraw` contains the full architecture diagram of the system.

## Important

**Note:** Go to Extensions in vscode and install Excalidraw.

Excalidraw is a collaborative whiteboard tool that allows you to draw diagrams and sketches.

Then click on `architecture.excalidraw` , select "Open with Excalidraw" from the context menu.
